# 📊 Insert Sample Properties into Database

## Step 1: Insert Sample Data

1. Go to your Supabase Dashboard
2. Click **"SQL Editor"** (left sidebar)
3. Click **"New query"**
4. Open the file: `supabase/seed.sql` in your project
5. Copy **all the SQL code** from that file
6. Paste it into the SQL Editor
7. Click **"Run"** (or press Ctrl+Enter)

You should see: "Success. 6 rows inserted"

---

## Step 2: Verify Data

1. Go to **"Table Editor"** (left sidebar)
2. Click on the **"properties"** table
3. You should see 6 properties listed!

---

## Step 3: Test Your Website

1. Go to: `http://localhost:3000/properties`
2. You should see all 6 properties from the database!
3. Try clicking on a property to see the detail page

---

**After inserting the data, your website will use real data from Supabase instead of mock data!** 🎉
