## 🚀 Guidelines: Building with AI (Cursor)

### **Best Practices:**

#### **1. Clear Communication** 💬
**Do:**
- ✅ Be specific about what you want
- ✅ Show examples if possible
- ✅ Ask for explanations
- ✅ Review code before accepting

**Example:**
- ✅ "Add a toast notification when form is submitted"
- ✅ "Create a property card component with image, title, price"
- ✅ "Show me how this works"

---

#### **2. Iterative Development** 🔄
**Do:**
- ✅ Build feature by feature
- ✅ Test each feature
- ✅ Fix issues before moving on
- ✅ Build on what works

**Example:**
- ✅ Build property listing first
- ✅ Test it works
- ✅ Then add search
- ✅ Then add filters

---

#### **3. Understand the Code** 📚
**Do:**
- ✅ Ask AI to explain code
- ✅ Read through changes
- ✅ Understand how it works
- ✅ Learn as you go

**Example:**
- ✅ "Explain how this component works"
- ✅ "What does this function do?"
- ✅ "Why did you use this approach?"

---

#### **4. Test Everything** ✅
**Do:**
- ✅ Test each feature
- ✅ Check for errors
- ✅ Verify functionality
- ✅ Test on mobile

**Example:**
- ✅ Submit a form → Does it work?
- ✅ Click a button → Does it do what it should?
- ✅ View on phone → Does it look good?

---

#### **5. Version Control** 📝
**Do:**
- ✅ Use Git (version control)
- ✅ Commit frequently
- ✅ Write clear commit messages
- ✅ Keep backups

**Example:**
- ✅ Commit after each feature
- ✅ "Add property listing page"
- ✅ "Fix toast notification bug"
