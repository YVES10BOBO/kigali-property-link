## 🚀 How to Use

### Access Dashboard
1. Go to: `http://localhost:3000/dashboard`
2. You'll see the overview with statistics

### View Inquiries
1. Click "Inquiries" in sidebar
2. Filter by status (New, Contacted, etc.)
3. Update status using dropdown
4. Contact customers via Email/Call/WhatsApp buttons

### Manage Properties
1. Click "Properties" in sidebar
2. Filter by status
3. Click "Add Property" to add new
4. Click "Edit" to modify existing
5. Click "Delete" to remove (with confirmation)
