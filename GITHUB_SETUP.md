# 🚀 How to Push to GitHub

## Step 1: Create GitHub Repository

1. Go to **https://github.com/new**
2. Repository name: `kigali-property-link` (or any name you prefer)
3. Description: "Real estate website for Kigali properties - Homart Properties agent"
4. Choose: **Public** or **Private** (your choice)
5. **DO NOT** check "Initialize with README" (we already have code)
6. Click **"Create repository"**

## Step 2: Copy Your Repository URL

After creating, GitHub will show you a URL like:
- `https://github.com/YOUR_USERNAME/kigali-property-link.git`

**Copy this URL** - you'll need it in the next step!

---

## Step 3: Run These Commands

After you create the repository, come back here and I'll help you push!

**Or if you want to do it yourself, run these commands:**

```bash
# 1. Add all files
git add .

# 2. Commit
git commit -m "Initial commit: Kigali Property Link website"

# 3. Add your GitHub repository (replace with YOUR URL)
git remote add origin https://github.com/YOUR_USERNAME/kigali-property-link.git

# 4. Push to GitHub
git push -u origin master
```

---

## ⚠️ Important Notes:

- Make sure you're logged into GitHub
- Replace `YOUR_USERNAME` with your actual GitHub username
- If you get authentication errors, you may need to use a Personal Access Token
